# ReinarPanel

Перед работой прочитай [CLAUDE.md](CLAUDE.md). Это общие правила проекта для Claude Code и Codex.

В Codex правь Python через `apply_patch`, чтобы после правки сработало автоформатирование. Навыки проекта вызываются через `$имя`, например `$verify`. Перед работой с API, SQL или фоновыми задачами сверяйся с ближайшей карточкой `CLAUDE.md` в каталоге сервиса.

Если доступен индекс [памяти проекта](.codex/claude-memory/MEMORY.md), прочитай его и открывай только относящиеся к задаче заметки.
